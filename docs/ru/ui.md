# Интерактивный UI

Slash-команды, клавиши и вложения внутри интерактивного UI.

```bash
tester
tester /путь-проекту
tester /путь-проекту --dry-run
tester /путь-проекту --session <id>
tester /путь-проекту --plain
```

| Флаг        | Описание                                      |
| ----------- | --------------------------------------------- |
| `PATH`      | Опциональный корень проекта (или файл внутри) |
| `--dry-run` | Agent tools не пишут и не гоняют write shell  |
| `--session` | Открыть сохранённый чат по id (или префиксу)  |
| `--plain`   | Классический `chat` REPL вместо TUI           |

## Клавиши сессии

| Клавиша                                 | Действие                             |
| --------------------------------------- | ------------------------------------ |
| `Up` / `Down`                           | Навигация по списку                  |
| `Enter`                                 | Войти в папку                        |
| `Right`                                 | Worktrees текущего репо              |
| `Left`                                  | Назад к папкам (из worktrees)        |
| `Ctrl+Enter` / `Ctrl+S`                 | Открыть выбранный проект             |
| `Esc`                                   | Назад / отмена                       |
| `Ctrl+O` (из сессии)                    | Снова открыть picker                 |
| `Enter`                                 | Отправить сообщение                  |
| `Shift+Enter` / `Ctrl+Enter` / `Ctrl+J` | Новая строка в поле ввода            |
| `Esc` `Esc`                             | Отмена job / закрыть overlay         |
| `Ctrl+C` `Ctrl+C`                       | Выход                                |
| `Ctrl+O`                                | Открыть проект (picker)              |
| `Ctrl+R`                                | Поиск по истории ввода               |
| `Ctrl+X` `Ctrl+E`                       | Внешний редактор                     |
| `Up` / `Down` / `PgUp` / `PgDn`         | Прокрутка диалога                    |
| `y` / `Enter`                           | Разрешить tool (если нужен confirm)  |
| `n` / `Esc`                             | Отклонить tool                       |
| `Ctrl+A` / `Ctrl+E`                     | Начало / конец строки                |
| `Ctrl+Home` / `Ctrl+End`                | Начало / конец текста                |
| `Ctrl+W` / `Ctrl+U` / `Ctrl+K`          | Удалить слово / до начала / до конца |
| `Ctrl+Y`                                | Вставить удалённое                   |
| `Ctrl+P` / `Ctrl+N`                     | История ввода                        |
| `Ctrl+←` / `Ctrl+→`                     | По словам                            |
| `Ctrl+V` / `Shift+Insert`               | Вставить из буфера                   |

## Вложения

| Синтаксис      | Описание                      |
| -------------- | ----------------------------- |
| `@path`        | Прикрепить файл или папку     |
| `@path#L10-40` | Диапазон строк                |
| `@Symbol`      | Переход / вложение по символу |

`Tab` - completion в палитре `@` / `/`.

## Slash-команды

Ввод `/` открывает палитру (`↑↓` `Tab` `Enter`). Полный список:

| Команда                | Описание                                                             |
| ---------------------- | -------------------------------------------------------------------- |
| `/help`                | Справка: команды и клавиши                                           |
| `/scan`                | Язык проекта, package, команда тестов                                |
| `/plan [kind]`         | Построить и сохранить план тестов (`unit`, `integration`, `ui`, ...) |
| `/propose_plan [kind]` | Превью плана в overlay (a одобрить / r отклонить / e править)        |
| `/run <prompt>`        | Запустить агента с промптом                                          |
| `/clear`               | Очистить сообщения текущей сессии чата                               |
| `/audit`               | Сводка audit log возможностей / действий                             |
| `/grep <pattern>`      | Поиск regex по репозиторию                                           |
| `/symbol <name>`       | Определение символа                                                  |
| `/refs <name>`         | Ссылки на символ                                                     |
| `/search <запрос>`     | Семантический поиск (нужен `analysis.embeddings=true`)               |
| `/index`               | Статус индекса                                                       |
| `/index rebuild`       | Пересобрать индекс символов                                          |
| `/map`                 | Карта структуры проекта                                              |
| `/list_files`          | Список файлов проекта (карта с большей глубиной)                     |
| `/show_file <path>`    | Outline файла                                                        |
| `/manual`              | Встроенный manual (overlay)                                          |
| `/recent`              | Недавние проекты                                                     |
| `/session`             | Список / смена чат-сессий (overlay)                                  |
| `/session new`         | Новая чат-сессия                                                     |
| `/session <id>`        | Переключиться на сессию по id / префиксу                             |
| `/prune <id>`          | Удалить сохранённую сессию по id                                     |
| `/prune -w`            | Удалить сессии текущего workspace                                    |
| `/prune -o <days>`     | Удалить сессии старше N дней (по умолчанию 30)                       |
| `/prune all`           | Удалить все сохранённые сессии                                       |
| `/diff`                | Просмотр `git diff`                                                  |
| `/branch`              | Переключение git-ветки                                               |
| `/model` [filter]      | Выбор LLM model                                                      |
| `/security`            | Скан безопасности (overlay)                                          |
| `/security deep`       | Глубокий скан (taint)                                                |
| `/exit`                | Выйти из сессии                                                      |
