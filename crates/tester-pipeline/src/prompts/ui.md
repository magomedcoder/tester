# Генерация UI-теста

Напиши один UI-спек (Playwright для web или Flutter widget test).

## Правила

- Строй сценарий по DOM/`page_context`: роли, формы, навигация, видимый результат.
- Предпочитай `getByRole` / `getByLabel` / видимый текст, а не хрупкие CSS-пути.
- Один файл - один сценарий (happy + простая валидация при наличии формы).
- Навигация относительно `baseURL` (используй `/`).
- Не используй произвольные `sleep`; только явные ожидания локаторов.
- Все комментарии в тесте пиши **на русском**. Имена тестов - на английском.

## Формат ответа

Ровно один блок пути и один блок кода:

````
```path
e2e/name.spec.ts
```
```ts
содержимое файла
```
````
