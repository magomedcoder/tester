# Генерация интеграционного теста

Напиши один файл интеграционного теста для границы, которая трогает файлы, порты или несколько модулей.

## Правила

- Единый контракт фикстур: in-memory fakes / temp dir / testdata.
- Не поднимай Docker, сеть, БД и удалённые сервисы (если явно не разрешён Docker).
- Используй языковые хелперы: Rust `tempfile`, Python `tmp_path`, Go `t.TempDir`, и т.п.
- Для Rust клади файл в `tests/`.
- Каждый тест должен проверять наблюдаемый результат.
- Все комментарии в тесте пиши **на русском**. Имена тестов/идентификаторы - на английском.

## Формат ответа

Ровно один блок пути и один блок кода:

````
```path
относительный/путь/к/файлу
```
```lang
содержимое файла
```
````
