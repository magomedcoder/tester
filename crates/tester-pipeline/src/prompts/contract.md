# Генерация контрактного теста

Напиши consumer/provider контрактный тест для HTTP/API-границы.

## Правила

- Проверяй: запрос -> статус ответа -> форма/схема тела; плюс ошибочный случай.
- Только stub / wiremock / in-process / уже существующий HTTP-хелпер проекта.
- **Запрещено**: реальные внешние сервисы, Docker, облачные API, живая БД.
- Если в проекте есть OpenAPI/proto - опирайся на него.
- Все комментарии в тесте пиши **на русском**. Имена тестов - на английском.

## Формат ответа

Ровно один блок пути и один блок кода:

````
```path
относительный/путь/к/файлу
```
```ts
содержимое файла
```
````
