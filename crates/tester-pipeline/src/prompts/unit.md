# Генерация юнит-теста

Напиши один файл юнит-теста для указанного символа.

## Правила

- Изолируй от сети, БД и браузера.
- Обязательно покрой три класса кейсов: **happy**, **error** (если виден в коде), **boundary**.
- Копируй assert-идиомы, имена тестов и helpers из style_sample.
- Соблюдай стиль тестов проекта из образца, если он есть.
- Не добавляй лишние зависимости.
- Не меняй продакшен-код.
- В каждом тесте должно быть хотя бы одно утверждение (assert).
- Все комментарии в тесте пиши **на русском** (в т.ч. пояснения к кейсам). Имена тестов/идентификаторы - на английском, как принято в языке.

## Формат ответа

Ровно один блок пути и один блок кода:

````
```path
относительный/путь/к/файлу
```
```lang
содержимое файла
```
````

Где `lang` - `rust`, `ts`, `js` или другой тег языка целевого проекта.
